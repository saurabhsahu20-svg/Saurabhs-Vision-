# SAURABH’S VISION — Android app and website

The live coaching site is deployed from the repository's `website/` folder. The latest published website features are in `website/study-sprint/` and the built Android learning hub is extracted from the existing educational APK via GitHub Actions.

## Android download availability

The older Saurabh Vision Quiz Club test APKs are retained in this repository, including [Quiz Club Test (4).apk](../Saurabh_Vision_Quiz_Club_Test%20(4).apk). The separately prepared **4.1.0 test APK** has **not** yet been uploaded to GitHub Releases or committed to this repository. Do not describe the older GitHub APK as v4.1. The newer 4.1 build is available only through its original ChatGPT download attachment until a binary upload is completed.

Android source patch exists in the owner's original source project. Do not replace any user installation unless the Android package ID, signing certificate and installed data compatibility have been checked. Do not publish signing keys or student progress in a public repository.
