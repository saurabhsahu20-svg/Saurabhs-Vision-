# S Browser 1.6 Beta — Saurabh Vision Learning App

**S Browser** · by **SAURABH'S VISION™**

## New homepage learning shortcut

The previous **NCERT, Khan Academy, Wikipedia and Google Scholar** homepage learning shortcut buttons have all been removed.

Under **SAURABH VISION LEARNING**, there is now exactly one large featured button:

**✦ Saurabh Vision Learning App ↗** → [Open the owner's hosted learning app](https://saurabhsahu20-svg.github.io/Saurabhs-Vision-/vision-app/).

This is the web version extracted and deployed through the owner's GitHub Pages workflow, not an APK installation button. It opens inside S Browser's WebView. Internet access is required. The GitHub Pages site may offer publicly available learning worlds, quizzes and study activities; backend features that require Firebase setup are not automatically activated.

## Other features preserved

- Offline 304-word English–Hindi dictionary and native Android WebView search, tabs, bookmarks, history and downloads.
- **CG Jobs & Exams** with official recruitment links and opt-in official page-change alerts.
- **CG City News**, plus **General and Sports News** with attributed dated publisher headlines.
- Daily Assembly & Fun: **31 bilingual daily thoughts, 31 speeches**, news, entertainment-only zodiac reflections, crosswords, riddles and word puzzles.
- Existing **S Browser** app name and neon S launcher icon.

## Download and verification

[GitHub v1.6 beta release](https://github.com/saurabhsahu20-svg/Saurabhs-Vision-/releases/tag/s-browser-v1.6.0-beta) — updated APK will appear after successful main-branch CI. Build requires JDK 17, Gradle 8.9, Android SDK 35. CI compiles and signs the APK and asserts the four removed shortcuts do not remain in the homepage code.

**Beta limitation:** A green Android build is not proof that the live learning site loads on every physical phone. Verify the public web content and HTTPS URL on a real device.
